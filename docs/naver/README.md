# 네이버 커머스API 원문 보관

`apicenter.commerce.naver.com` 은 외부 조회가 차단돼 있어 문서를 자동으로 가져올 수 없다.
필요한 섹션을 브라우저에서 복사해 이 폴더에 텍스트로 저장한다.

| 파일 | 원문 경로 | 쓰임 |
|---|---|---|
| `auth.md` | 인증 — 전자서명 생성, 인증 토큰 발급 요청 | 모든 호출의 전제 |
| `order.md` | 주문 — 조회 API 목록, 폴링 권장 방식, 상태값 | 주문 수집 · State Machine |
| `product.md` | 상품 — 등록·수정, 원상품/채널상품 | 상품등록 |
| `solution-doc.md` | 커머스솔루션 — JWE, 이벤트훅, 요금제, 입점 절차 | 솔루션 경로를 택할 때 |

## 우선순위

경로(대행사/솔루션/판매자별)가 미정이어도 `auth.md` 와 `order.md` 면 어댑터를 만들 수 있다.
경로에 따라 달라지는 것은 토큰 발급 시 `type`(SELF/SELLER)과 `account_id` 두 값뿐이다.
