# 고객 관리하기 | 커머스API

고객 관리하기

커머스솔루션마켓과 연관된 질의 외, 솔루션 관련 고객 CS 인입 시 개발사로 모두 라우팅됩니다.

판매자가 솔루션 사용 시 필수적으로 확인해야 할 내용이 있다면

솔루션 등록 시 반드시 아래의 필수 고지 항목 영역을 통해 명확히 안내하셔야 합니다.

입력하신 내용은 아래와 같이 판매자가 솔루션 구독 시 체크박스를 통해 반드시 체크해야 하는 영역으로 출력됩니다.

커머스솔루션마켓은 솔루션을 소개하고 솔루션 이용 신청을 할 수 있도록 판매, 중개하는 서비스를 의미하므로

솔루션의 판매 등 거래와 관련하여 솔루션 제공업체 또는 판매회원을 대리하지 않습니다.

따라서 솔루션과 관련된 해지는 처리하지 않으므로 솔루션사에서 고객과 소통하여 솔루션 해지를 진행해야 합니다.

심사후승인형 솔루션이라면, 지속적으로 신청 건에 대한 관리가 필요합니다.

커머스솔루션마켓 외 타 채널 (e.g. 자사몰, 타 오픈마켓)에서 운영중인 기운영 솔루션 사용자가 커머스솔루션마켓에서도 구독 신청 시, 중복 결제 방지를 위해 '승인 거절'이 필요합니다.

커머스API로 고객 상태 및 비즈월렛 결제 내역을 실시간 조회가 가능합니다. 지속적인 모니터링을 통해 원활한 솔루션 운영 부탁드립니다.

점검 및 장애로 인해 솔루션 사용자의 불편 및 서비스 중단이 생길 경우, 사용자에게 안내 및 사전 공지가 필요합니다.

사용자의 요청에 응답하는데 오랜 시간이 걸리지 않아야 합니다.
