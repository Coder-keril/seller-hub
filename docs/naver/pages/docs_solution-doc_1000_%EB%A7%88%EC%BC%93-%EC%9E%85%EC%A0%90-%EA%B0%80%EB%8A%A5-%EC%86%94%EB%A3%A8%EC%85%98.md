# 마켓 입점 가능 솔루션 | 커머스API

On this page
마켓 입점 가능 솔루션

커머스솔루션은 스마트스토어 판매자가 오로지 판매에만 집중할 수 있도록 돕기 위한 것으로,

스토어 개설부터 배송, 고객관리, 정산까지 판매 여정의 영역 전반에 걸쳐 다양한 솔루션으로 커머스솔루션 마켓 입점이 가능합니다.

다양하고 좋은 솔루션은 언제든지 환영합니다. 다만, 입점을 위해 최종 심사 과정을 거치셔야하는 점을 참고해 주셔야합니다.

판매자들이 널리 이롭게 사용 중인 솔루션​

판매자들이 직접 들려주는 생생한 솔루션 사용 경험을 소개합니다.
이미지 클릭 시, 후기 영상으로 랜딩됩니다.
