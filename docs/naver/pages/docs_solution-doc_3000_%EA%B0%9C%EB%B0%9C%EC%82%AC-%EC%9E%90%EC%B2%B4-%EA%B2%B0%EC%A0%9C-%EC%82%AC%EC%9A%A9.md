# 개발사 자체 결제 사용 | 커머스API

개발사 자체 결제 사용
솔루션의 결제수단은 네이버 비즈월렛을 기본으로 합니다.

비즈월렛 사용이 어려운 경우  링크 를 클릭하여 검토 요청 부탁드립니다.

검토 요청을 통해 협의를 완료한 경우에만, 개발사 자체 결제 사용이 가능합니다.

개발사 자체 결제는 개발사 페이지 내 자체적으로 연동하신 외부PG, 자체적으로 운영하시는 계좌입금 등이 포함됩니다.

판매자가 솔루션 사용 시 개발사 자체 결제를 통한 과금을 잘 인지할 수 있도록

솔루션 등록 시 반드시 아래의 별도 과금 안내 영역을 통해 과금 정책을 상세하게 입력하셔야 합니다.

입력하신 내용은 판매자가 아래와 같이 솔루션 소개 페이지를 통해 확인할 수 있습니다.

또한 커머스솔루션마켓에서 유입된 사용자에 대한 모든 결제 내역은, 반드시 외부 개발사 자체 결제 내역 전송 API 를 통해 전송하셔야 합니다.

호출하신 데이터는 커머스솔루션마켓에서 솔루션 거래 현황 파악 및 정산 시 참고 자료로 활용될 예정입니다.

상세한 활용 정책 및 방식은 추후 업데이트 예정이며, 우선적으로는 데이터 취합만 진행됩니다.

API 호출 시, 아래 내용을 참고 부탁드립니다.

커머스API 활용을 위한 공통 인증 프로세스가 존재합니다. ( 관련 문서 바로 가기 )

솔루션 등록 완료 후 표시되는 솔루션 애플리케이션 ID 로 토큰 발급이 필요하며, 토큰 발급 타입(type)이 SELF로 설정되어 있어야 호출이 가능합니다.

거래 금액은 VAT 포함 을 기준으로 합니다.

리포팅 정합성을 위하여 진행되는 주요 유효성 검사 항목은 아래와 같습니다.

전송된 인증 토큰과 연결된 개발사가 관리 가능한 솔루션이 있는지, 관리 가능한 solutionld 를 입력했는지 확인합니다.

이미 동일한 paymentId 로 전송된 적이 있는지 확인합니다.

환불 내역 (transactionType = REFUND) 을 전송한 경우, originalPaymentId 를 전달하였는지 확인하며,

이에 해당하는 기존 결제 내역이 (transactionType = PAYMENT) 존재하는지 확인합니다.
