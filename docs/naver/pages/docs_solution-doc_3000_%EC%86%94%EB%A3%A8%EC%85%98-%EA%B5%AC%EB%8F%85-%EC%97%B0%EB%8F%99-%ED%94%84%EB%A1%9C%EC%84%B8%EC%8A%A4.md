솔루션 구독 연동 프로세스
판매자 식별​

솔루션 개발사가 솔루션을 구독중인 판매자의 정보를 API로 이용하려면 판매자의 식별자 정보를 알고 있어야 합니다.

솔루션 개발자분들이 솔루션을 구독하는 판매자의 정보를 API로 호출하기 위한 식별자를 획득하는 방법을 크게 2가지 방식을 제공하고 있습니다.

[기본] '바로 사용' 유형 (JWT 토큰 사용)​

정의 : 판매자가 솔루션 구독을 완료한 즉시 솔루션을 바로 이용할 수 있습니다.

"네이버페이 비즈 월렛" 결제 솔루션인 경우 솔루션 구독과 동시에 이용 요금 결제가 완료됩니다.

판매자 식별 정보 취득:

판매자는 솔루션 구독 직후 곧바로 [사용하기] 버튼을 선택하여 솔루션 웹 사이트 영역으로 이동할 수 있습니다.

[사용하기] 버튼으로 솔루션 영역 이동 시 JWT가 HTTP GET 파라미터로 전달됩니다.

수신 JWT의 유효성 검증 후 유효 JWT 수신으로 판단하였다면 스마트스토어센터에서 정상 접근한 판매자로 신뢰할 수 있습니다.

[선택] '심사 후 승인' 유형 (JWE 토큰 추가 사용)​

정의 : 판매자는 솔루션 사용 신청 후 솔루션 개발사의 사용 승인 이후에 솔루션을 정상 이용할 수 있습니다.

판매자는 (커머스솔루션마켓) 솔루션 사용 신청 후 → (솔루션 영역) 구독 신청 절차를 계속 이어서 진행합니다.

솔루션 영역에서 '판매자 커머스ID 인증'을 최초 1회 수행해야 합니다.

추가정보 수집 등의 솔루션 구독 심사가 필요한 경우 재량으로 처리합니다.

솔루션 개발사는 판매자의 (커머스솔루션마켓) 솔루션 사용 신청에 대하여 (솔루션 영역) 필요한 신청 절차를 바탕으로 심사를 거쳐, 승인을 (사용 시작 승인 API 호출 처리) 하거나, 거절을 (사용 시작 거절 API 호출 처리) 할 수 있습니다.

만약 솔루션 개발사의 승인 및 거절 없이 판매자의 사용 신청 90일이 경과되면, 커머스솔루션마켓에서 자동으로 판매자의 솔루션 사용 신청을 거절 처리합니다.

"네이버페이 비즈 월렛" 결제 솔루션인 경우 솔루션의 사용 승인 시점에 이용 요금 결제가 완료됩니다.

판매자 식별 정보 취득:

'판매자 커머스ID 인증' 과정을 설계-구현해야 합니다.

JWE 토큰 값은 판매자의 '판매자 커머스ID 인증' 성공 시 솔루션에서 지정한 URL로 랜딩하는 과정에서 HTTP GET 파라미터로 전달됩니다.

판매자의 솔루션 이용을 허락하려면 가장 최신의 JWE 토큰 값을 이용하여 '사용 승인 API'를 호출합니다. API 호출 성공 직후 판매자는 솔루션 구독을 시작합니다.
