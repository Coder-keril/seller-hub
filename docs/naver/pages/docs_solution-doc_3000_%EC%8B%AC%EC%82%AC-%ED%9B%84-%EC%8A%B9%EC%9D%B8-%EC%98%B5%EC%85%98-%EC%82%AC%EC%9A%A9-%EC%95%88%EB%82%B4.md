심사 후 승인 유형​

심사 후 승인 옵션은 솔루션을 등록하는 시점에 선택이 가능한 부분입니다.

판매자가 솔루션 구독 신청을 하는 경우, 심사 후 승인 옵션을 사용하는 경우
개발사에서 구독 신청건에 대한 , 사용 승인을 해야지 구독이 시작 되는 방식입니다.

해당 옵션을 사용하는 경우는 아래와 같습니다.
기본적으로 구독신청을 한 판매자에 대해서 판단이 필요한 경우에는 심사 후 승인을 해주는 옵션을 고려해 볼 수있습니다.

해당 옵션을 사용하지 않고, 우선 결제 후 환불을 하는 방식도 존재하나, 너무 많은 환불이 발생하는 경우에는 판매자의 CS가
문제가 되어 솔루션 품질에 영향이 미치므로 권장하지 않습니다.

사용 목적설명비고특정 판매자만 구독가능한 경우가령 상품 등록 100개 이상 판매자만 솔루션 활용이 가능한 경우 구독 요청 시점에 즉시 판별 불가-심사가 필요한 경우가입시 특정 정보를 입력 후 활용이 가능한 솔루션인 경우,구독 신청 후 개발사 페이지에서정보 입력 후 구독 승인 필요-기보유 고객의 중복 가입을 막아야하는 경우기 운영중인 솔루션에서 구독중인 판매자의 중복 구독 여부판단 후 구독을 허용해야 하는 경우-

연동 시 고려사항​

심사 후 승인 옵션 고려시에는 2가지 사항을 고려해야합니다.

구독 신청을 했음에도 즉시 구독 승인을 하지 못하므로 중간에 이탈하는 판매자가 발생하게 됩니다.

심사 후 승인 옵션은 해당 옵션 미사용 대비해서 추가적으로 연동 개발 비용이 발생하게 됩니다.

심사 후 승인 옵션을 사용하는 방법은 솔루션 등록시점에 설정이 가능합니다.
아래와 같이 솔루션 등록시 '고급옵션'을 클릭하여 구현을 진행해야 하며, 인증구현도 함께 구현하는 것을 권장합니다.

심사 후 승인 옵션은 개발사에서 구독 신청건에 대해서 승인 API를 호출하여, 결제 및 구독을 시작할 수 있게 해주셔야합니다.
따라서 심사요청건에 대한 승인을 자동으로 처리 할 수 있도록 개발사에서 준비 하는 것을 권장드립니다.

심사 후 승인이 지연되는 경우, 마켓에서 판매자에게 메일을 발송하게 되어 있으며, 90일 동안 승인 되지 않는 경우에는
구독 신청을 했더라도 마켓에서 자동으로 철회 하도록 (구독 신청 취소) 조치됩니다.

구체적인 개발 구현 방식에 대해서 요소에 대해서는 위키 문서를 참고해주시거나, 기술 문의 채널을 통해서 안내를 받으시면됩니다.

심사 후 승인 옵션 사용시에는 요금제를 선택하더라도 실제 결제 금액은 발생하지 않습니다. 심사 승인시 결제가 발생하기 때문입니다.

현재 결제 금액은 0원이지만, 결제에 필요한 자동충전 설정은 구독신청시 필요합니다.

정기 결제 정보는 승인 이후에 날짜가 확정되며, 회차 시작일도 심사 승인 후 발생하게 됩니다.
