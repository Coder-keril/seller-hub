커머스 API 센터란?​

커머스 API 센터는 개발사 솔루션을 마켓에 입점시키려면 필요한 플랫폼입니다.

커머스 API 센터에 가입하기 위해서는 스마트스토어로 판매자 계정을 먼저 등록해 주셔야 합니다.

판매자 계정 생성이 필수인 이유는, 개발사가 제작한 솔루션의 테스트를 위해서 보유하신 스마트스토어 계정이 필요하기 때문입니다.

다만 스마트스토어 입점시 등록하신 사업자 정보와 개발사로 활용할 사업자 정보가 동일해야 하며, 해당 사업자 계정의 계좌로 정산
대금이 지급되기 때문에 가입시 이점 유념해 주셔야 합니다.

솔루션 입점 준비​

커머스API센터를 통해서 솔루션을 등록해야 하므로, API센터 계정 생성이 필수적으로 진행되어야 합니다.

커머스 API 센터에서 현재 스마트스토어 통합매니저만 계정 생성이 가능합니다.

단, 솔루션 마켓 입점동의를 진행한 개발사를 대상으로만 [매니저초대] 기능을 제공하고 있습니다.

이 경우 초대를 통해, 스마트스토어센터에 권한이 없는 커머스ID 회원도 API센터 권한을 보유할 수 있습니다.

커머스 API 센터 계정 생성 후에는, 추가로 마켓 입점 동의를 진행해 주셔야 하며 동의 이후에는 솔루션 등록을 할 준비가 완료됩니다.

커머스 API 센터 솔루션 마켓 입점 동의는 법인 사업자만 가능합니다. (안정화 이후 점진적으로 확대 예정입니다.)

솔루션 판매시 현금영수증 증빙을 위해서 고객센터 전화번호 등록을 필수로 진행해 주셔야합니다.

솔루션 등록하기​

개발사에서 구현중이신 솔루션과 커머스 API 및 솔루션 등록을 위한 테스트솔루션 등록 단계를 거치게 됩니다.

테스트솔루션등록은 어떠한 심사도 진행되지 않으며 개발사의 판매자 계정에서만 보이고, 구독할 수 있습니다.

해당 상태에서 비즈월렛 결제를 진행하더라도 실제 결제 차감되지 않습니다.

업그레이드 및 해지 등 다양한 테스트를 진행하며, HOOK 이벤트를 받고 개발사에서 제공하는 서비스의 상태와 잘 동기화되는지

자체적으로 테스트 하셔야 합니다.

심사요청을 하시게되면 심사 담당자에 의해서 심사가 진행됩니다. 심사 요청 시 마켓에 노출될 일자를 지정할 수 있습니다.

심사는 입점 가능 여부, 솔루션 콘텐츠의 이슈여부, 보안 위반 여부 등 다양한 항목으로 심사를 진행합니다.

심사 결과는 메일로 안내되며, 반려 시 사유를 확인하여 신규 심사요청을 하시면 됩니다.

심사 승인이 완료되어 마켓에 노출된 솔루션의 컨텐츠 수정은 별도의 심사가 없습니다. 다만, 주기적으로 내부 모니터링이 진행되며

문제가 되는 솔루션은 별도의 고지 없이 마켓노출이 중지될 수 있습니다.
