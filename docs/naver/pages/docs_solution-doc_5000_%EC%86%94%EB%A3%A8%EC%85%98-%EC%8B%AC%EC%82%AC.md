# 솔루션 심사 | 커머스API

On this page
솔루션 심사
솔루션 배포 준비가 완료되면, 커머스솔루션마켓 사용자에게 최고의 솔루션을 제공하기 위해 솔루션 심사를 진행합니다.
개발사는 솔루션에 대한 체크리스트를 확인하고 심사 요청을 해야 합니다.

심사 요청 후, 솔루션 심사팀에서 솔루션에 대한 심사를 진행하며 심사가 승인되어야 커머스솔루션마켓에 노출됩니다.

솔루션 심사 요청 후, 심사 완료까지 평균 7~14 영업일 소요될 수 있습니다.

심사 요청을 할 수 있는 조건​

아래 3가지 조건을 모두 만족해야만 솔루션 심사 요청이 가능합니다.

솔루션 구독 이력

솔루션을 구독한 계정이 존재한 이력이 있어야 심사 요청이 가능합니다.

내솔루션 > 마켓 노출 영역 '테스트 노출' 클릭 후, 솔루션 상세페이지에서 솔루션을 추가하시면 됩니다.

솔루션 IP 등록

API호출을 위한 IP가 1개 이상 등록되어야 심사 요청이 가능합니다.

솔루션 등록하기 > 솔루션 애플리케이션 > API호출 IP를 등록 부탁드립니다.

API 그룹 추가 사유 입력

솔루션 등록하기 > 솔루션 애플리케이션 > API사용 > 선택한 API의 'API 그룹 추가 사유'를 200자 이상 작성 부탁드립니다.

심사 요청 방법​

내솔루션 > 관리 > '심사요청' 버튼을 클릭해 심사요청서를 작성합니다.
