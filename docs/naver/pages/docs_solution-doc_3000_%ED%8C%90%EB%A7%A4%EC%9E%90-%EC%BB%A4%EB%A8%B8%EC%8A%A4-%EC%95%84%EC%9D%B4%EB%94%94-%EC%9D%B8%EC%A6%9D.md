# 판매자 커머스 아이디 인증 | 커머스API

판매자 커머스 아이디 인증
(심사 후 승인형 전용)

전체 프로세스​

판매자 커머스ID 인증​

판매자가 네이버 외부 사이트에서도 커머스ID로 안심하고 인증할 수 있는 서비스입니다.

솔루션사는 솔루션을 사용하는 판매자의 커머스ID 인증을 통해 판매자의 스마트스토어 정보, 솔루션 사용 정보 등을 안전하게 처리할 수 있습니다.

기존 스마트스토어센터의 API관리 메뉴를 이용한 대행사 선택 기능은 커머스솔루션마켓에서는 이용하지 않습니다.

인증 프로세스​

판매자는

커머스솔루션마켓에서 원하는 솔루션을 선택하고 추가하기를 클릭합니다.

요금제 결제 및 정보 제공 동의를 진행합니다.

솔루션 사이트로 이동하여 솔루션 사이트 회원 가입 등의 구독 신청 과정을 완료합니다.

마지막으로, 커머스ID 인증 창에서 판매자 커머스ID 인증을 진행합니다.

이후 솔루션사는

판매자 커머스ID 인증 성공 시 지정 URL(Redirect URL)로 전달되는 판매자 인증 JWE를 수신합니다.

JWE 해석 API를 호출하여 토큰 형태의 판매자 인증 JWE를 분석 가능한 형식으로 변환합니다.

분석한 판매자 정보가 솔루션 사용 조건을 만족하면 사용 승인 API를 호출합니다.

단, 솔루션 사용 조건을 만족하지 않으면 사용 시작 거절 API를 호출할 수 있으며 승인 또는 거절 없이 판매자의 구독 신청 90일이 경과되면 커머스솔루션마켓에서 자동으로 판매자의 솔루션 구독 신청을 거절 처리합니다.

사용 승인 API 호출 응답이 HTTP 200(OK)라면 앞에서 JWE 해석 API를 호출하여 얻은 판매자 계정 UID로 솔루션 서비스에 필요한 판매자 정보를 호출할 수 있습니다.

판매자 커머스ID 인증은 판매자의 솔루션 구독 신청 단계에서 최초 1회만 필요합니다.

단, 구독 신청 취소 후 재신청 시 판매자는 커머스ID 인증을 처음부터 다시 진행해야 합니다.

연동 필수 요소​

커머스API를 이용한 사용 정보, 판매자 정보 연동 및 솔루션의 이벤트 훅 수신 구조체를 개발해야 합니다.

판매자 커머스ID 인증 프로세스를 솔루션 사이트 UX와 매끄럽게 연결하여 판매자에게 안내해야 합니다.

판매자가 솔루션을 사용 해지하면 커머스솔루션마켓과 약속한 방법으로 구독 해지 정보를 연동해야 합니다.

'JWE 해석 API'와 '사용 승인 API'의 차이점​

JWE 해석 API는 판매자 인증 JWE 토큰에 담긴 판매자의 솔루션 구독 정보를 안전하게 조회하는 용도입니다.

커머스ID 인증을 활용한 판매자 커머스ID 인증 성공 시 판매자 인증 JWE가 프런트엔드 환경을 통해 솔루션 사이트에 전달됩니다.

판매자 인증 JWE는 토큰 형태로, JWE 해석 API를 호출하여 분석 가능한 형식으로 변환해야 판매자의 솔루션 구독 정보를 확인할 수 있습니다.

JWE 해석 API 호출만으로는 판매자의 솔루션 구독 신청이 승인되지 않습니다.

사용 승인 API는 대상 판매자의 솔루션 구독 신청을 승인하는 용도입니다.

"네이버페이 비즈 월렛"으로 이용요금을 결제하는 유료 솔루션이라면 사용 승인 API 호출로 판매자의 솔루션 사용 상태가 '사용중' 전환되고, 사용자의 비즈 월렛 잔고가 차감되어 이용요금 결제가 완료됩니다.

반대로 사용 시작 거절 API는 대상 판매자의 솔루션 구독 신청을 거절하는 용도입니다.
사용 시작 거절 API 호출 시 포함하신 사유가 판매자에게 안내되며 판매자의 솔루션 구독 신청이 취소됩니다.
솔루션 개발사의 승인 및 거절 없이 판매자의 구독 신청 후 90일이 경과되면, 커머스솔루션마켓에서 자동으로 판매자의 솔루션 구독 신청을 거절 처리합니다.

설계 유의사항​

판매자 커머스ID 인증 성공 시 Redirect URL로 지정하는 URL의 도메인은 사용자가 솔루션 사이트에서 '커머스ID 인증' 창을 띄우는 URL 도메인과 동일하거나 하위의 서브 도메인이어야 합니다.

도메인이 다르거나 상위 레벨의 도메인에서는 '커머스ID 인증' 창 호출을 허용하지 않습니다.

예시) Redirect URL이 https://api.commerce.naver.com/join 이라면 허용 규칙은 *api.commerce.naver.com에 한함.

✔ api.commerce.naver.com , sub.api.commerce.naver.com (허용)

❌ commerce.naver.com , example.commerce.naver.com , smartstore.naver.com , api.commerce.naver.com.io (허용 안 함)

JWE 해석 API는 대상 솔루션 애플리케이션 ID로만 정상 해석 결과 확인이 가능합니다. 따라서 복수의 솔루션 애플리케이션 ID 운용 시 Redirect URL은 다른 경로로 설정하는 것을 권장합니다.
