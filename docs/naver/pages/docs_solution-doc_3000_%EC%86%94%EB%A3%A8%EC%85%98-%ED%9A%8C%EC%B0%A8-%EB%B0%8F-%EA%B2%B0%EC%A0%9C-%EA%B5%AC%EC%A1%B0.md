솔루션 회차 및 결제 구조
월 회차 기간 이해하기​

커머스솔루션마켓의 모든 사용자는, 구독중인 각 솔루션마다 월 회차 기간을 가집니다.

각 사용자 및 솔루션 마다 다른 월 회차 기간을 가질 수 있습니다.

무조건 각 사용자의 각 솔루션 1회차 시작일을 기준으로,  매월 해당 일자가 회차 시작일이 됩니다.

단, 회차 시작일이 월 말 (29,30,31일) 인데, 해당 일자가 없는 월의 경우에는 해당 월의 마지막 일자가 회차 시작일이 됩니다.

회차 종료일은 다음 회차 시작일의 전일을 의미합니다.

월 사용요금이 무료이더라도 월 사용요금 결제만 발생하지 않을 뿐, 월 회차 기간은 존재합니다.

월 사용요금 결제 이해하기​

월 사용요금이 유료라면, 마켓에서 자동으로 각 사용자x솔루션의 월 회차 기간에 따라 매월 결제가 처리됩니다.

사용자가 직접 솔루션을 추가하는 시점에, 선택된 요금제로 1회차 월 사용요금이 즉시 결제되고 솔루션 사용이 시작됩니다.

이후 월 회차 기간에 따라, 매월 다음 회차 시작 3일 전부터 월 사용요금이 선불로 정기 결제되며, 해당 회차 종료일에 매출이 확정됩니다.

결제 시 스마트스토어 판매자의 비즈월렛 충전금이 사용되며,

3일간 최대 10회까지 시도되다가 최종 결제까지 (회차 시작일 전일 23:30) 실패하면 강제 해지됩니다.

매출 확정 이전까지는 개발사에서 사용자마다 금액을 직접 지정하여 환불이 가능하지만,

매출 확정 이후에는 환불이 불가하므로, 매출 확정 이후에는 환불이 불가하므로, 필요 시 개발사에서 직접 수기 대응이 필요합니다.

확정된 매출은 익월 5영업일에 개발사의 비즈월렛으로 정산됩니다.

무료체험일 제공 CASE​

단, 무료 체험일을 제공할 경우, 사용자가 직접 솔루션을 추가하는 시점에, 1회차 월 사용요금이 즉시 결제되지 않습니다.

솔루션 사용은 즉시 시작되더라도 월 회차 기간이 무료 체험 종료 이후에 시작되므로, 해당 기간에 따라 월 사용요금 정기 결제가 시작됩니다.

심사후승인형 솔루션 운영 CASE​

솔루션 유형 별 사용 시작 시점

바로사용형: 사용자가 솔루션 추가 즉시 1회차 결제 및 사용이 시작

신청후승인형: 사용자가 솔루션 신청 시, 개발사에서 자체적으로 심사에 필요한 추가정보를 입력 받아 승인을 완료하면 (승인API 호출) 1회차 결제 및 사용이 시작

바로사용형 유형이 아닌, 심사후승인형 유형의 솔루션인 경우에도, 1회차 월 사용요금이 즉시 결제되지 않습니다.

사용자가 직접 솔루션을 신청한 후, 개발사에서 승인을 완료하면 1회차 월 사용요금이 결제되고 솔루션 사용이 시작됩니다.

단, 월 사용요금이 무료인 경우, 승인이 되면 1회차 월 사용요금 결제 없이 솔루션 사용이 시작됩니다.

월 사용요금 업/다운그레이드 이해하기​

월 사용요금이 높은 요금제일수록, 사용자가 요금제 변경 시 업그레이드로 처리됩니다.

사용자의 월 사용요금 요금제 업/다운그레이드가 이루어질 경우,

중간에 정기 결제되는 월 사용요금 금액이 변경될 수 있으나, 월 회차 기간은 변경되지 않습니다.

업그레이드의 경우,

사용자가 업그레이드를 진행하려면 이번 회차 종료일까지 일할계산된 추가 결제가 필요하며, 추가 결제 완료 즉시 업그레이드가 반영됩니다.

반면 다운그레이드의 경우,

사용자가 다운그레이드를 신청하면 이번 회차 종료일까지는 기존 요금제가 유지되며 (다운그레이드 예약중),

다음 회차부터 다운그레이드가 반영됩니다.

(단, 다음 회차 정기 결제가 완료된 이후 다운그레이드 신청 시, 다운그레이드 완료 후 차액 환불 처리됩니다.)

해지 이해하기​

유료 월 사용요금 CASE​

사용자가 해지 신청 시, 월 사용요금이 유료인 경우에는, 우선 해지 예약 상태에 돌입하게 됩니다.

해지 예약 상태에서는 다음 회차 정기 결제가 진행되지 않습니다.

(단, 다음 회차 정기 결제가 완료된 이후 해지 신청 시, 해지 완료 후 전액 환불 처리됩니다.)

해지 예약 상태로 이번 회차 종료 시, 마켓 시스템에서 자동으로 솔루션이 해지 완료 처리되며, 매출이 확정됩니다.

무료 월 사용요금 CASE​

사용자가 해지하는 즉시 해지가 완료됩니다.

단, 월 사용요금이 무료일지라도, 조건부 해지 운영 시에는,

사용자가 해지 신청 후 개발사에서 해지 승인이 되어야 (사용 해지 승인 API 호출) 해지가 완료됩니다.

개발사 강제 해지​

사용자가 해지하지 않아도, 개발사에서 필요 시 강제 해지 처리가 (사용 중지 API 호출) 가능합니다.

강제 해지 처리 즉시 해지가 완료됩니다.

개발사 정산​

개발사 정산은 결제 시점과는 무관하게, 매출 확정 시점을 기준으로 진행됩니다.

'회차완료일 +1영업일' 에 개발사 비즈월렛으로 정산되며, 해당 회차완료일의 완료매출에서 수수료를 제외한 금액이 충전됩니다.
