커머스솔루션마켓이란​

커머스솔루션마켓은 90만 스마트 스토어 판매자가 장사에만 집중할 수 있도록 필요한 솔루션을 제공하는 마켓입니다.

스마트스토어를 사용하는 판매자의 대부분은 솔루션을 1개 이상 구독을 하고 있습니다.

커머스솔루션을 제공하는 개발사에게 솔루션 마켓은 판매자와 만날 수 있는 유용한 채널입니다.

솔루션 동작 방식​

솔루션마켓에 솔루션 입점시 커머스 API를 통해 솔루션을 만들어야 합니다. (커머스API보기)

커머스API는 솔루션을 구독한 판매자에게 솔루션을 만들 수 있도록 다양한 API 를 제공하고 있습니다.

커머스API 센터를 통해서 커머스 API를 활용하여 제작한 솔루션은 테스트 > 심사 과정을 거쳐 입점하게 됩니다.

커머스솔루션마켓 제공 기능​

솔루션마켓은 개발사의 솔루션이 판매자의 구독으로 이어질 수 있도록 플랫폼을 제공합니다.

솔루션 운영시 발생하는 다양한 이슈에 대해서 다양한 수단을 제공하여 개발사가 효율적 관리가 가능하게 합니다.

마켓주요기능설명구독관리솔루션의 구독신청, 회차 진행, 구독해지결제판매자의 정산 대금 지급 수단인 비즈월렛을 통한 솔루션 비용 결제정산현금영수증 발행을 통해서 솔루션 구매시 정산 증빙 처리솔루션소개솔루션 소개 페이지를 제공하여 판매자에 솔루션 도달을 지원기술지원판매자의 구독, 업그레이드 등 다양한 운영 대응시 개발사에 HOOK 및 API 지원
