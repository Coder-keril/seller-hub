# 심사 요청서 | 커머스API

심사 요청서
심사 요청서 작성 방법을 안내해 드립니다.

No.구분설명①재심사 여부재심사를 요청하는 경우, 직전 심사 요청의 반려 사유를 확인할 수 있습니다.
 직전 심사 반려 사유를 확인하시어, 향후 심사가 원활히 진행될 수 있도록 조치 부탁드립니다.②심사 승인 이후 솔루션 노출 방식- 즉시 노출 : 솔루션 심사 완료되는 즉시 커머스솔루션마켓 내 노출됩니다.
 - 예약일 노출 : 솔루션 심사 이후, 설정한 예약일에 커머스솔루션마켓 내 노출됩니다. 솔루션 승인일이 설정한 예약일 보다 늦을 경우, 심사 완료 즉시 노출됩니다.③테스트 기본 정보솔루션 심사 과정에서 솔루션 시작, 해지 테스트에 필요한 테스트 ID/PW 작성 부탁드립니다.
 솔루션 구독 및 해지를 어떻게 해야 하는지 자세히 작성해야 원활한 심사가 가능합니다.④기운영 솔루션 체크마켓 입점 시점에 기운영중인 솔루션이 있을 경우, 체크 박스를 클릭 합니다.
 기운영 솔루션이 있을 경우, 심사후승인형 옵션으로 솔루션 운영이 필요합니다. (관련 문서)⑤앱솔루션 정보 입력솔루션 앱이 있을 경우, 체크 박스를 클릭합니다. Redirect URL을 사용하는 솔루션 모바일 앱이 있는 경우, 'Custom Tabs'로만 구현해야 합니다. (Webview 구현 불가)
솔루션 심사 요청 시, Custom Tabs 구현 여부 모니터링을 위해 Class name, Flow name 작성 및 로그인 절차와 관련된 각 단계가 설명되어 있어야 하며, 각 단계별 클래스 호출되는 Flow 설명이 필요합니다.⑥솔루션 구독, 해지 테스트 영상솔루션 심사팀에서 참고할 수 있는 솔루션 구독, 솔루션 해지 테스트 영상 첨부 부탁드립니다.
최대 3개까지 등록 가능합니다.
