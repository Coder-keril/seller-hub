# 솔루션 운영 중단 및 개발사계정 관리 | 커머스API

솔루션 운영 중단 및 개발사계정 관리
솔루션 운영 중단​

솔루션 운영 중 일시적으로 운영 중단을 희망하는 경우, 솔루션 문의포럼으로 직접 문의 부탁드립니다.

개발사계정 탈퇴​

아래 6가지 조건에 해당되지 않는 개발사계정에 한하여 계정 탈퇴가 가능합니다.

내스토어 애플리케이션이 상태가 활성 혹은 비활성(제재)인 경우 탈퇴 불가

탈퇴하고자 하는 개발사 계정으로 운영 중인 솔루션이 1개 이상인 경우 탈퇴 불가

해당 개발사가 운영 중인 솔루션을 구독하는 계정 수가 1개 이상인 경우 탈퇴 불가

정산상태가 정상이 아닌 경우 탈퇴 불가

정산 예정이거나 정산 중지된 금액이 0원이 아닌 경우 탈퇴 불가

네이버페이 비즈월렛 총 잔액이 0원이 아닌 경우 탈퇴 불가

개발사계정 양도양수​

커머스API센터에서는 양도양수를 지원하지 않습니다.

만일 스마트스토어센터 판매자계정에서 양도양수가 발생하는 경우, 커머스API센터 기존 계정에서 등록된 모든 애플리케이션은 삭제처리됩니다.

판매자계정 양수자는 기존 개발사계정 이용이 불가하며, 새로운 개발사계정을 생성해 주셔야 합니다.

개발사계정 통합매니저 변경​

커머스API센터에서는 통합매니저 변경을 자체적으로 지원하지 않습니다.

만일 스마트스토어센터 판매자계정에서 통합매니저 위임이 발생하는 경우,

위임받은 신규 통합매니저가 개발사 계정 생성 절차를 진행하면 기존의 개발사계정 사용이 가능합니다.

단,커머스API센터 기존 계정에서 등록된 모든 애플리케이션은 삭제처리되니 이 점 유의 부탁드립니다.
