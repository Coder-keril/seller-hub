# 솔루션 등록 프로세스 리뷰 | 커머스API

솔루션 등록 프로세스 리뷰

솔루션을 마켓에 노출하기 위해서는 ① 솔루션 상태 ② 마켓 노출 ③ 심사 상태에 대해서 이해가 필요합니다.

솔루션 상태는 " 테스트등록 - 심사중 - 운영중 - 운영종료" 상태로 구분 됩니다.

솔루션 상태설명테스트등록    심사를 요청하기 전 개발사에서 다양한 테스트를 진행할 수 있는 상태입니다.심사중      테스트 등록에서 [심사요청] 버튼을 클릭 후, 심사요청서 작성 시 심사중 상태로 전환됩니다.
 심사 반려 되는 경우, 테스트등록 상태에서 심사요청을 다시 진행 주시면 됩니다.운영중      심사가 승인 된 경우에는 운영중 상태로 변경되게 됩니다.
 심사가 승인된 운영중은 전체 판매자에게 노출 되는 상태입니다. 마켓 노출 상태는, 노출/미노출로 구분입니다.
  다만 노출 상태라 하더라도 테스트 등록 솔루션 상태인 경우에는 개발사 대상으로만 해당 솔루션이 보여지며 다른 판매자 계정에서는 해당 솔루션을 조회 할 수 없습니다.
  미노출은 어드민을 통해서 변경가능 하며, 사후 모니터링에서 위반사항이 적발 되는 경우에는 개발사에 고지 후 마켓에서 솔루션이 보여지지 않는 미노출 상태로 변경 되어 질 수 있습니다.
