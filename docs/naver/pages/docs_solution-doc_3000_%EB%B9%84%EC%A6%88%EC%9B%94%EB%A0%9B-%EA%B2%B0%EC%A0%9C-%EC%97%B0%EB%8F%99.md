# 비즈월렛 결제 연동 | 커머스API

비즈월렛 결제 연동
개발사에서 요금제만 잘 세팅하면 결제는 커머스솔루션에서 자동으로 처리되므로,

개발사에서는 비즈월렛 결제 시스템 자체를 연동하는 것이 아니라, 커머스솔루션마켓 정보를 연동하여, 유료 솔루션을 쉽게 운영할 수 있습니다.

API센터를 통해 솔루션 등록 시 요금제를 추가합니다. ( 요금제 추가 방법 확인하기 )

발급된 요금제 ID 를 개발사의 자체 요금제와 매핑하여 관리합니다.

커머스솔루션마켓으로 유입된 구독자의 판매자 계정 ID 를 인식하고, ( 구독자 식별 방법 확인하기 )

이벤트 훅을 수신하여 개발사의 자체 고객 정보를 업데이트합니다. ( 이벤트 훅 확인하기 )

위 2. 3. 을 조합하여 개발사의 서비스를 운영합니다.

필요 시 API 를 통해 개발사가 직접 실시간 결제 현황 조회가 가능합니다.
