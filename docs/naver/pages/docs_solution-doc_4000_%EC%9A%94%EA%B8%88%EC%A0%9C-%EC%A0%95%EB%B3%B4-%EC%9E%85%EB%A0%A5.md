# 요금제 정보 입력 | 커머스API

요금제 정보 입력
아래 내용을 참고하시어 요금제 정보를 입력하셔야 합니다.

무료 체험일

사용자에게 최초 1회 제공되는 혜택으로, 필요 시 4일 이상으로 자유롭게 입력하실 수 있습니다.

수시로 수정하실 수 있으며, 사용자는 최초 사용을 시작할 당시에 입력되어 있는 무료 체험일이 적용됩니다.

요금제 정보

요금제는 1개 이상 20개 이하로 추가하실 수 있으며, 6개까지 동시 노출이 가능합니다.

심사 요청 이후에는 삭제 및 노출 여부를 제외한 모든 정보 수정이 불가하니 주의 바랍니다.

요금제 ID

중복 없이 자동 발급되는 수정 불가한 값으로, 요금제 운영 시 매핑 key로 사용하실 수 있습니다.

노출 여부

커머스솔루션마켓> 솔루션 소개&추가/신청 페이지 내 요금제 카드 노출 여부를 의미하며, 수시로 수정하실 수 있습니다.

미노출 시 신규 사용자는 발생할 수 없으나, 기존 사용자는 솔루션 사용이 유지되므로 주의 바랍니다.

유형

현재는 무료, 월간 결제 만 선택하실 수 있으며, 연간 결제 등 다른 옵션은 준비 중입니다.

요금제명

스타트, 플러스, 프로 와 같이, 사용자가 요금제를 명확히 인지할 수 있도록 작성 바랍니다.

월 사용요금

200만원 이하로 입력 가능하며,

입력하신 월사용요금으로 구독자에게 최초 회차 결제 및 향후 정기 결제가 선불로 시도됩니다.

정기 결제는 다음 회차 시작일 3일전부터 최대 10회 시도합니다.

실패 시 사용자에게 스마트스토어센터 알림 및 메일이 발송되며, 최종 실패 시 회차 시작 직전 강제해지 처리됩니다.

단, 솔루션 심사 승인 이전에는 테스트를 위해 입력하신 월사용요금과 무관하게 0원으로 처리되니 혼선 없으시길 바랍니다.

월 사용요금이 높은 요금제일수록, 사용자가 요금제 변경 시 업그레이드로 처리됩니다.

 (요금제 변경 세부 case 확인하기)

입력하신 내용은 판매자가 아래와 같이 솔루션 소개 페이지를 통해 확인할 수 있습니다.

판매자가 무료 요금제 선택 시에는, 아래와 같이 솔루션 결제 페이지 상 결제가 발생하지 않습니다.

판매자가 유료 요금제 선택 시에는, 아래와 같이 솔루션 결제 페이지 상 최초 회차 결제가 선불로 시도됩니다.

또한 판매자는 솔루션 결제에 필요한 비즈월렛 자동충전 수단을 필수로 등록해야 합니다.
